# 김준희 포트폴리오 토큰 스튜디오

## 실행

이 폴더에서 `node portfolio-studio-server.mjs`를 실행하고 http://127.0.0.1:4175/ 를 엽니다.

## 편집

왼쪽에서 28개 토큰의 색상, 간격, 타이포그래피, 모서리, 그림자, 모션을 편집합니다. 오른쪽 대시보드와 실제 포트폴리오 미리보기에 즉시 반영됩니다. 대시보드의 수치는 예시 데이터입니다.

변경값은 현재 브라우저에 자동 저장됩니다. 원본 비교, 개별 복원, 실행 취소 및 다시 실행을 지원합니다. 원본 포트폴리오 파일을 직접 덮어쓰지는 않습니다.

## Figma

`Figma JSON 내보내기` → `JSON 다운로드`를 선택합니다. Figma의 Tokens Studio 플러그인에서 JSON을 가져오고 `global` 세트를 활성화한 뒤 변수와 스타일을 생성합니다. Figma 기본 파일 가져오기 형식이 아닌 Tokens Studio 형식입니다.

저장한 JSON은 스튜디오의 `JSON 가져오기`로 다시 편집할 수 있습니다.
